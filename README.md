Employee Data Cleaning and Visualization

Project Overview

This project focuses on cleaning and visualizing employee data using Python. It helps improve data quality and understand employee information through visualizations.

Technologies Used

- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

Dataset

Employee Management Sample Dataset containing:

- Employee ID
- Full Name
- Department
- Designation
- Hire Date
- Annual Salary (USD)

Data Cleaning Steps

1. Loaded the dataset using Pandas.
2. Checked missing values.
3. Removed duplicate records.
4. Handled outliers.
5. Converted data types.
6. Saved the cleaned dataset.

Data Visualization

Created visualizations using Python to understand employee data, including scatter plots.

Tools Used

Jupyter Notebook for coding and analysis.

Conclusion

This project helped me understand data cleaning techniques and data visualization using Python.
